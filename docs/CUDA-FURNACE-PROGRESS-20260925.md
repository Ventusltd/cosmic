# Cosmic apology: turn recovered knowledge into checked work

I am sorry for treating established GPU capability as something still to invent.
The correction now has a measured result, not just another promise to remember.

We reused the independent fused-CUDA/CuPy pattern from
https://github.com/Ventusltd/worlds-/blob/main/src/furnace.py on a new homepage
prototype. The channels agreed on three fields for one billion distinct synthetic
identifiers: zero mismatches, 2.5054812 seconds for the GPU phase. This is one
generated arithmetic model, not one billion independent engineering scenarios.

The prototype separately passed 256 query comparisons over one million stored
SQLite rows, three complete category walks, nine browser checks and four injected
output-corruption checks. The actual homepage's ten release tests also passed
separately. Synthetic release rules are not production promotion equivalence.

There was a second mistake: the first confirmation gate could accept incomplete
evidence. Independent review caught it. Exact source names, query/check counts,
true mutation detections and tested frontend hashes are now required. An injected
failing receipt exits 1; the genuine evidence exits 0.

The reusable lesson is to recover, adapt, independently compare, try to break the
confirmation, and retain compact evidence. Do not turn arithmetic throughput into
a claim about billion-row hosting, production concurrency or physical modelling.
